The first public release: your Android phone as a Windows webcam over a USB cable.

## What's in it

- **Plugcam Camera** for desktop apps and browsers: Zoom, Discord, Telegram Desktop, OBS, Chrome, Edge, Firefox.
- Up to 1080p at 30 fps (60 fps on phones that support it). H.264 is encoded in hardware on the phone and decoded on the PC's graphics chip.
- Back and front camera, every lens the phone lets apps use, zoom with 1×/2×/5× presets, flashlight, rotation, mirror.
- Color: brightness, contrast, saturation and warmth, changed live and applied on the PC.
- A live preview in the window, a first-run guide for USB debugging, the tray, start with Windows.
- **Updates itself.** Plugcam checks GitHub once a day (you can turn that off) and installs a new version when you click *Update*, then shows what changed. Every update is signed.
- **Installer or portable.** The installer adds Plugcam to the Start menu; the portable zip runs from any folder and keeps its settings next to it.
- **Light.** A 7.4 MB download. Closed to the tray, Plugcam shuts its window down completely: 8 MB of memory while it waits, under 1% of the CPU while it streams.
- 13 languages: English, Deutsch, Español, Français, Italiano, Polski, Português (Brasil), Türkçe, Українська, Русский, 日本語, 한국어, 简体中文.

## Install

- **Installer:** download `Plugcam_0.1.0_x64-setup.exe` below and run it. It asks for administrator rights once, to register the camera.
- **Portable:** download `Plugcam_0.1.0_x64-portable.zip`, extract it anywhere and run `Plugcam.exe`. On the first start it asks for administrator rights once, to add the camera to Windows.

The files are not code-signed yet, so SmartScreen may warn you: *More info → Run anyway*. The `.sha256` files next to
them have the checksums (`Get-FileHash .\Plugcam_0.1.0_x64-setup.exe`).

## Known limitations

- USB only; Wi-Fi comes next.
- Microsoft Store apps (like the Windows Camera app) don't see the camera; desktop apps and browsers do.
- Android 12 or newer.
- No sound: use the PC's microphone.
- Tested with a OnePlus 11R on Android 15. Other phones should work; if yours doesn't, please open an issue with the model.

## По-русски

Первый публичный релиз: Android-телефон как веб-камера для Windows по USB-кабелю.

- **Plugcam Camera** видна в Zoom, Discord, Telegram Desktop, OBS, Chrome, Edge и Firefox.
- До 1080p и 30 кадров/с (60 на телефонах, которые это умеют).
- Основная и фронтальная камера, выбор объектива, зум с кнопками 1×/2×/5×, фонарик, поворот, зеркало.
- Цвет: яркость, контраст, насыщенность и теплота, меняются на лету.
- Превью в окне, мастер включения отладки по USB, работа из трея, автозапуск.
- 13 языков интерфейса.
- Обновляется сама: раз в день проверяет GitHub (можно выключить), ставит новую версию по кнопке «Обновить» и показывает, что изменилось. Каждое обновление подписано.
- Установщик или portable: установщик добавляет Plugcam в меню «Пуск», portable-архив запускается из любой папки и хранит настройки рядом с собой.
- Лёгкий: загрузка 7,4 МБ. Свёрнутый в трей, Plugcam полностью закрывает окно: в ожидании он занимает 8 МБ памяти, а во время трансляции — меньше 1% процессора. Видео декодирует видеокарта.

Установщик пока без цифровой подписи: если SmartScreen предупредит, нажмите «Подробнее → Выполнить в любом случае».
Пока только USB (Wi-Fi следующим), приложения из Microsoft Store камеру не видят, нужен Android 12+.
