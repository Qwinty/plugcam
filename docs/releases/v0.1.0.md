The first public release: your Android phone as a Windows webcam over a USB cable.

## What's in it

- **Plugcam Camera** for desktop apps and browsers: Zoom, Discord, Telegram Desktop, OBS, Chrome, Edge, Firefox.
- Up to 1080p at 30 fps (60 fps on phones that support it), hardware H.264 on the phone, Windows' own decoder on the PC.
- Back and front camera, every lens the phone lets apps use, zoom with 1×/2×/5× presets, flashlight, rotation, mirror.
- A live preview in the window, a first-run guide for USB debugging, the tray, start with Windows.
- 13 languages: English, Deutsch, Español, Français, Italiano, Polski, Português (Brasil), Türkçe, Українська, Русский, 日本語, 한국어, 简体中文.

## Install

Download `Plugcam_0.1.0_x64-setup.exe` below and run it. It asks for administrator rights once, to register the camera.
The installer is not code-signed yet, so SmartScreen may warn you: *More info → Run anyway*. The `.sha256` file next to
it has the checksum (`Get-FileHash .\Plugcam_0.1.0_x64-setup.exe`).

## Known limitations

- USB only; Wi-Fi comes next.
- Microsoft Store apps (like the Windows Camera app) don't see the camera; desktop apps and browsers do.
- Android 12 or newer.
- No sound: use the PC's microphone.
- Tested with a OnePlus 11R on Android 15. Other phones should work; if yours doesn't, please open an issue with the model.

## По-русски

Первый публичный релиз: Android-телефон как веб-камера для Windows по USB-кабелю.

- **Plugcam Camera** видна в Zoom, Discord, Telegram Desktop, OBS, Chrome, Edge и Firefox.
- До 1080p и 30 кадров/с (60 на телефонах, которые это умеют).
- Основная и фронтальная камера, выбор объектива, зум с кнопками 1×/2×/5×, фонарик, поворот, зеркало.
- Превью в окне, мастер включения отладки по USB, работа из трея, автозапуск.
- 13 языков интерфейса.

Установщик пока без цифровой подписи: если SmartScreen предупредит, нажмите «Подробнее → Выполнить в любом случае».
Пока только USB (Wi-Fi следующим), приложения из Microsoft Store камеру не видят, нужен Android 12+.
