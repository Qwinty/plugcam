Lenses that Plugcam hid can be shown again.

## Fixed

- **A hidden lens stayed hidden for good.** When a lens sends no picture over USB, Plugcam hides it for that phone model and switches to the main camera. Until now it could only be brought back by editing the settings file. The *Camera* section now lists the hidden lenses with a *Show again* button, so you can try them again.

## Install

- **Already have Plugcam?** It offers this update by itself; click *Update*. To check right away: *Settings → Updates → Check now*.
- **Installer:** download `Plugcam_0.2.2_x64-setup.exe` below and run it.
- **Portable:** download `Plugcam_0.2.2_x64-portable.zip`, extract it anywhere and run `Plugcam.exe`.

The files are not code-signed yet, so SmartScreen may warn you: *More info → Run anyway*. The `.sha256` files next to
them have the checksums.

## По-русски

Скрытые объективы можно вернуть.

- **Скрытый объектив оставался скрытым навсегда.** Если объектив не отдаёт картинку по USB, Plugcam скрывает его для этой модели телефона и включает основную камеру. До сих пор вернуть его можно было только правкой файла настроек. Теперь в разделе «Камера» видны скрытые объективы и кнопка «Показать», чтобы попробовать их снова.

Если у вас уже стоит Plugcam, он сам предложит обновление — нажмите «Обновить».
