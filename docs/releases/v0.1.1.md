A lighter window and a small layout fix.

## What's new

- **About 80 MB less memory while the window is open.** The window now draws without the graphics chip, which such a simple window doesn't need. With the preview running Plugcam takes about 204 MB instead of 277 MB; with the camera off, 83 MB instead of 166 MB. The window looks the same, see-through background included.
- The 1×/2×/5× zoom presets now sit on the right, under the zoom buttons.

## Install

- **Already have Plugcam 0.1.0?** It offers this update by itself; click *Update*. To check right away: *Settings → Updates → Check now*.
- **Installer:** download `Plugcam_0.1.1_x64-setup.exe` below and run it.
- **Portable:** download `Plugcam_0.1.1_x64-portable.zip`, extract it anywhere and run `Plugcam.exe`.

The files are not code-signed yet, so SmartScreen may warn you: *More info → Run anyway*. The `.sha256` files next to
them have the checksums.

## По-русски

Окно стало легче, плюс небольшая правка интерфейса.

- **Примерно на 80 МБ меньше памяти, пока открыто окно.** Окно теперь рисуется без видеокарты: такому простому окну она не нужна. С превью Plugcam занимает около 204 МБ вместо 277 МБ, с выключенной камерой — 83 МБ вместо 166 МБ. Внешне ничего не изменилось, полупрозрачный фон на месте.
- Кнопки зума 1×/2×/5× теперь справа, под кнопками приближения.

Если у вас уже стоит 0.1.0, Plugcam сам предложит обновление — нажмите «Обновить».
