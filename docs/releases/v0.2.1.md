Updating Plugcam no longer stops at "Error opening file for writing".

## Fixed

- **The update got stuck on adb.exe.** The installer showed *Error opening file for writing* for `adb.exe`, `AdbWinApi.dll` or `AdbWinUsbApi.dll`. The adb server that Plugcam starts to talk to the phone kept running after Plugcam closed, and it held those files open. The installer now stops that server before replacing its files. If it won't stop, the installer moves the old files aside and they are removed after a restart. Uninstalling had the same problem and now works too.

If an earlier update is stuck on that message right now: open Task Manager, end *adb.exe*, then click *Retry*.

## Install

- **Already have Plugcam?** It offers this update by itself; click *Update*. To check right away: *Settings → Updates → Check now*.
- **Installer:** download `Plugcam_0.2.1_x64-setup.exe` below and run it.
- **Portable:** download `Plugcam_0.2.1_x64-portable.zip`, extract it anywhere and run `Plugcam.exe`.

The files are not code-signed yet, so SmartScreen may warn you: *More info → Run anyway*. The `.sha256` files next to
them have the checksums.

## По-русски

Обновление Plugcam больше не останавливается на ошибке «Error opening file for writing».

- **Обновление застревало на adb.exe.** Установщик показывал «Error opening file for writing» для `adb.exe`, `AdbWinApi.dll` или `AdbWinUsbApi.dll`. Plugcam запускает adb-сервер, чтобы общаться с телефоном, и этот сервер продолжал работать после закрытия Plugcam, держа файлы открытыми. Теперь установщик сначала останавливает сервер. Если тот не останавливается, установщик отодвигает старые файлы в сторону, и они удаляются после перезагрузки. При удалении Plugcam была та же проблема, теперь исправлена и она.

Если прошлое обновление прямо сейчас стоит на этой ошибке: откройте Диспетчер задач, завершите *adb.exe* и нажмите *Retry* (Повторить).

Если у вас уже стоит Plugcam, он сам предложит обновление — нажмите «Обновить».
