Plugcam now works over Wi-Fi, no cable needed.

## What's new

- **Wi-Fi.** Open *Phones and Wi-Fi* in the side panel and pick a way:
  - **QR code** (Android 11+): on the phone, *Developer options → Wireless debugging → Pair device with QR code*, then scan the code Plugcam shows.
  - **Pairing code** (Android 11+): enter the six digits from *Pair device with pairing code*.
  - **From cable**: with the phone on the cable and on the same Wi-Fi, one click moves it to Wi-Fi and you can unplug. This link is not encrypted and ends when the phone restarts.
- **Remembered phones.** A paired phone connects by itself next time it shows up on the network. You can also pin which phone to use; by default Plugcam takes the first ready one, USB first.
- **No growing delay.** Over Wi-Fi the phone sends a key frame every second. When the picture falls more than half a second behind, Plugcam skips ahead to the next one instead of playing the backlog. If that keeps happening, it lowers the bit rate.
- **Reconnects on its own.** If the phone drops off the network, Plugcam tries to bring it back up to five times. Apps keep showing the last picture meanwhile, so a call doesn't lose the camera.
- Tips in the Wi-Fi window for when the phone is not found: same network, guest networks, the phone's hotspot, the Windows firewall prompt for adb.exe.

## Install

- **Already have Plugcam?** It offers this update by itself; click *Update*. To check right away: *Settings → Updates → Check now*.
- **Installer:** download `Plugcam_0.2.0_x64-setup.exe` below and run it.
- **Portable:** download `Plugcam_0.2.0_x64-portable.zip`, extract it anywhere and run `Plugcam.exe`.

The files are not code-signed yet, so SmartScreen may warn you: *More info → Run anyway*. The `.sha256` files next to
them have the checksums.

## По-русски

Plugcam теперь работает по Wi-Fi, без кабеля.

- **Wi-Fi.** Откройте «Телефоны и Wi-Fi» в боковой панели и выберите способ: QR-код или код сопряжения (Android 11+, «Для разработчиков → Отладка по Wi-Fi»), либо «С кабеля» — одна кнопка переводит подключённый кабелем телефон на Wi-Fi. Последний способ не шифруется и работает до перезагрузки телефона.
- **Запомненные телефоны** подключаются сами, когда появляются в сети. Телефон можно закрепить; по умолчанию берётся первый готовый, USB раньше Wi-Fi.
- **Задержка не копится.** Если картинка отстала больше чем на полсекунды, Plugcam перескакивает к свежему кадру, а при частых отставаниях снижает битрейт.
- **Сам переподключается**, если телефон пропал из сети: до пяти попыток, приложения всё это время видят последний кадр.

Если у вас уже стоит Plugcam, он сам предложит обновление — нажмите «Обновить».
